# 具身智能机器人示范数据管理工具

参与蚂蚁灵波具身智能挑战赛，团队获得三等奖，排名 5/1850。本人负责数据采集和模型推理优化，本仓库展示项目中的示范数据整理与场景分析工具。

## 项目任务

| 任务 | 机器人操作 |
| --- | --- |
| 水果蔬菜抓放 | 抓取指定物品，放入指定颜色的盘子 |
| 化妆品收纳 | 抓取指定化妆品，放入收纳盒的上、中、下层 |
| 双臂垃圾清扫 | 将纸团扫入簸箕，再倒入垃圾篓 |

## 我的工作

- 参与真实机器人遥操作示范采集，记录不同任务、物品组合和初始摆放。
- 建立样本首帧索引，关联任务指令、数据来源和初始场景。
- 开发本地浏览页面，按任务和场景查看样本，标记抓取目标，人工复核分类结果。
- 对比官方与自采数据的物品和目标位置覆盖，制定补采计划。
- 承担模型推理优化相关工作。当前仓库展示数据工具部分。

## 使用方法

安装依赖后，用索引脚本处理自己的图片目录。

```bash
python -m pip install -r requirements.txt
python generate_examples.py
python index_scenes.py --own demo=examples/frames --task demo=pick_place --output scene-index.json
```

打开 `scene-library.html`，点击「导入场景索引」，选择生成的 `scene-index.json`。示例目录中的几何图形用于验证导入和场景分组，页面中的示例不代表真实机器人评测结果。

处理 LeRobot 数据或视频时，按实际格式安装 PyArrow，并确保 FFmpeg 可用。脚本通过任务指令识别任务，任务不明确时可手动指定。浏览页面支持样本搜索、来源筛选、场景复核及分组清单导出。

本仓库中的首帧匹配采用图像特征相似度。相似场景和不明确的目标需要人工复核，实际泛化收益需要通过训练与真机任务验证。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index_scenes.py` | 从图片目录或 LeRobot 导出目录构建索引 |
| `scene-library.html` | 本地数据集浏览、搜索与场景复核 |
| `examples/frames/` | 人工绘制的几何图形示例 |
| `generate_examples.py` | 生成人工绘制的示例图 |
